# LLM‑агент для нефтегазовых расчётов

Данный репозиторий содержит LLM‑агента, разработанного в рамках научно-исследовательской работы (НИР) по теме:  
**«Разработка LLM-агента на основе прикладных скриптов студента»**.

Агент объединяет авторские Python‑скрипты для нефтегазовых расчётов в единую систему, управляемую через естественно‑языковые запросы. 
В качестве языковой модели используется локальная open‑source модель **Qwen3:8b** (запускается через **Ollama**) с механизмом **function calling**.

---

## Возможности

- **agent.py** – ядро агента.

  *Что делает*: управляет всем циклом взаимодействия с пользователем и LLM.

- **tools.py** – реестр инструментов и обёртки.

  *Что делает*: преобразует авторские расчётные скрипты в единый интерфейс, понятный LLM-агенту.

- **2D симуляция пласта** – скрипты: **oil_reservoir.py**, **visualization.py**.

  *Что делает*: Моделирование пластового давления в пористой среде с неоднородной проницаемостью в присутствии системы скважин посредством решения уравнения пьезопроводности (неявная конечно‑разностная схема).
- **Радиальная фильтрация со стволом скважины** – скрипт: **well_chisl.py**.

  *Что делает*: Расчет радиальной фильтрации в цилиндрических координатах с учётом влияния ствола скважины (wellbore storage). Метод конечных разностей на логарифмической сетке, метод прогонки Томаса (неявная схема).
- **Построение геологических карт** – скрипты: **well_map_builder.py**, **Irap.py**, **AbstractMap.py**, **SimpleMap.py**.

  *Что делает*: Чтение данных инклинометрии и карт поверхностей в формате IRAP, построение траекторий скважин, отображение точек среза, зон дренирования и секторов поиска.

**Единый интерфейс** – все расчёты вызываются через JSON‑параметры, результаты возвращаются в структурированном виде.

**Автономный выбор инструментов** – агент сам определяет, какой скрипт запустить и какие параметры передать, на основе запроса пользователя.

**Сохранение результатов** – все графики и карты сохраняются в папку `output/`.

## Архитектура

| Компонент | Описание |
|-----------|----------|
| **Пользовательский интерфейс** | CLI / интерактивный режим (PyCharm, терминал) |
| **LLM‑планировщик** | Qwen3:8b через Ollama с function calling |
| **Реестр инструментов** | Словарь `TOOLS` и JSON‑схемы `OPENAI_STYLE_TOOLS` |
| **Расчётные ядра** | Авторские скрипты: `oil_reservoir.py`, `visualization.py`, `well_chisl.py`, `well_map_builder.py` и др. |
| **Хранилище результатов** | Папка `output/` – PNG, HTML |

---

## Требования

- **Python** 3.10 или выше
- **Ollama** с загруженной моделью `qwen3:8b` (или аналогичной)
- **Библиотеки**:
  - `numpy`, `matplotlib`, `scipy`, `plotly`, `pandas`, `openpyxl`, `requests`
